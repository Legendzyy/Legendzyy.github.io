# Yiyao Zhang — Personal Homepage

Personal academic homepage for Yiyao Zhang, built with semantic HTML, modern CSS, and lightweight vanilla JavaScript.

## Local preview

Open `index.html` directly, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Updating the site

- Main content: `index.html`
- Visual styling: `style.css`
- Language and interactions: `script.js`
- Profile image and favicon: `assets/`

The website is designed for GitHub Pages and requires no build step.
